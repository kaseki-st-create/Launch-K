# マイク診断の手順（内蔵・USB・Bluetoothを見分けるための確認）

目的：マイクが「内蔵」「USB」「Bluetooth」のどれなのかを、機器の**名前**ではなく、Windowsが持っている**情報**で判定できるか、実機の値で確かめます。
この診断は、何も変更しません（読むだけです）。なお、アプリ本体も、同じ情報で、USB・Bluetoothのマイクを「内蔵マイク」と誤って表示しないようにしています（一覧に出る名前が変わるだけで、ミュートの動きは変わりません）。

## 準備
- 確認したいマイクを、すべて接続しておきます（内蔵・USBのfifine・Bluetoothのsoundcoreなど）。
  - Bluetoothのイヤホンは、PCにつないだ状態にしてください。
- Launch-Kのソースがあるフォルダで、PowerShell を開きます（`npm install` が済んでいること）。

## 実行
```
node tools/mic-selftest.js --props
```
- 画面に、マイクごとの情報が表示されます。
- 同じ内容が、`mic-props-report.txt` に保存されます（保存先を変えるときは `--out 保存先`）。

## 共有
- `mic-props-report.txt` の内容を、そのまま貼ってください。
- **共有する前に**、機器のシリアル番号などが含まれていないか、確認してください。含まれていたら、その部分は伏せて構いません。

## 見るところ（参考）
- 「【推定】」の行：今のところの、内蔵／USB／Bluetoothの推定です。
- 「容器ID」の行：`00000000-0000-0000-ffff-ffffffffffff` なら、本体（内蔵）を表します。
- 「バスの手がかり」の行：USB・BTHENUM・HDAUDIO などの文字が見つかった場所です。

## そのほかの確認（任意）
- `node tools/mic-selftest.js` … マイクの一覧とミュート状態を表示（変更なし）
- `node tools/mic-selftest.js --worker` … アプリと同じ、別スレッド経由で一覧が取れるかを確認（変更なし）
- `node tools/mic-selftest.js --mute-test` … 各マイクを、ミュート → 確認 → 元に戻す（配信・通話中は避けてください）
