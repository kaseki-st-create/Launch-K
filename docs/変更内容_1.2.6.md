# Launch-K 1.2.6 の変更内容（GitHubリリース用）

## マイク
- **「マイク（すべてまとめて）」**（今までの「マイク」ボタン）：接続中のすべてのマイクをまとめてミュート・解除します。1台でも開いていればミュート、すべてミュート済みのときだけ解除します。仮想デバイス・ミキサー・デジタル入力は自動で対象外（設定で個別にも外せます）。新しく挿したマイクも自動で対象になります。
- **「マイク（1台ずつ）」**（新規）：選んだ1台だけを切り替えます。つながっている間だけ使えます（抜くとグレーになり、設定は残ります）。同じマイクを別のボタンには選べません。表示名の変更・「元の名前に戻す」・「つないだ瞬間に自動でミュート」に対応。
- ノートPCの内蔵マイクは、「マイク配列（長いドライバ名）」ではなく、「内蔵マイク」と表示します（元の名前は小さく添えます）。内蔵向けのドライバ名（Intel・Realtek・AMDなど）が付いたものだけが対象で、USBカメラや会議用機器などの外付けの「マイク配列」は、そのままの名前で表示します。同じ表示名が複数あるときは（2）を付けます。
- 一部のマイクだけ開いているとき・状態を確認できないときは、ボタンの右上に「!」を表示します。
- **USB・Bluetoothのマイクを、「内蔵マイク」と誤って表示しないようにしました**。Windowsが持っている接続の情報（USB・Bluetoothの経路、容器ID）で、外付けと分かったものは、名前が「マイク配列」でも内蔵にしません。名前が「マイク配列」だけのときは、本体の容器IDと分かった場合だけ内蔵にします。情報を読めなかったときは、今までどおり名前だけで判断します（表示名が変わるだけで、ミュートの動きは変わりません）。
- **スマホにも、マイクの「!」を出すようにしました**。一部のマイクだけ開いているとき・状態を確認できないときに、PCと同じオレンジの「!」がボタンの右上に出ますまた、マイクが未接続・未選択のボタンは、PCと同じく、スマホでも薄く表示します（PCからスマホへ渡す状態を、ミュート／開いている／一部／不明／未接続／未選択の文字にしました）。
- マイクの設定画面で、マイクを選ぶたびに画面がちらつく問題を修正。説明文を整理しました。設定画面を開いたままマイクを挿す・抜くと、一覧が更新されます。
- ミュートした後は必ず読み直して確認します。確認できなかったときは「ミュート中」と表示しません。
- マイクの処理は専用スレッドで行い、固まってもアプリ（Launch-0を含む）は止まりません。
- タスクトレイに「すべてのマイクのミュートを解除」を追加。
- スマホ（Launch-0）からも、今までどおりマイクをミュート・解除できます。「スマホからはミュートだけ」にしたい人向けのチェックを、Launch-0の画面に追加。失敗・拒否はスマホにも「失敗」として返ります。

## 接続（Launch-0）
- 通信が一時的に確認できなくても、約15秒までは切断せずに待ちます（Tailscaleの停止・別の端末への入れ替わりは、今までどおり即切断）。
- **通信が途切れたときの切断を、6分から10分にしました**。2分で警告する点は同じですが、PCのLaunch-0の画面に、途切れている時間と、切断までの残り時間を表示するようにしました。
- **スマホの画面を閉じる・別のアプリに切り替えるなどでページが裏に回ったときも、10分で切断するようにしました**（今までは5分）。2分たつと、PCのLaunch-0の画面に、時間と残り時間つきの警告を出します。
- Tailscaleの確認の頻度を減らして、PCが重いときの誤切断を減らしました。
- ファイアウォールの許可が、いまのLaunch-Kの場所と合っているかを確認し、合っていなければ「許可を修正」ボタンを表示します（管理者の確認は1回）。日本語以外のWindowsで、ユーザー名に漢字を含む場合も、誤って警告しません。
- 管理者権限のスクリプトが、結果をファイルに書かないようにしました（結果は終了コードで受け取ります）。

## 表示
- **スマホの☰メニューを改良しました**。
  - 「接続の安全」を、初めは簡易表示（接続先のPC・経路・通信状態）にしました。見出しをタップすると、今までの詳細表示になります。開閉は、その端末に保存されます。
  - 横画面では、画面一覧を2列（1・2／3・4／5・6の順）にして、☰の中身を上下にスクロールできるようにしました（切断ボタンは下に固定）。詳細表示を開くと、見える位置まで自動でスクロールします。縦画面は今までどおりです。
- **スマホの長押しの名前表示**を、0.62秒で出て、指を離して1.2秒後に消えるようにしました（今までは0.67秒と1.8秒）。
- **スマホのサブページ切り替え（◀▶）と☰ボタンの、タップできる範囲を上下に広げました**（見た目や位置は変わりません。縦画面でも横画面でも、隣のボタンとは重なりません）。
- **スマホにマイクのオン/オフ（図柄・色）が反映されない不具合を修正**（PCからスマホへ渡す状態の許可リストに、マイクのボタンが入っていませんでした）。
- Launch-0で、PC側でマイクの接続・ミュートが変わったとき、2秒ごとの定期更新を待たずに、すぐスマホへ反映するようにしました。
- ヘッドホン・イヤホンのCSSアイコンを、オン/オフ対応にしました（オフのとき斜線が付きます）。オン用にオン/オフ対応のアイコンを選ぶと、オフ用にも同じものが自動で入ります。
- オン用・オフ用のCSSアイコンを使うボタンは、**オフ（ミュート中）のときの色を別に選べる**ようにしました（選ばなければ、今までどおり赤）。スマホにも反映されます。
- CSSアイコンの一覧が、アクセントカラーではなく、選んでいる色で表示されるようにしました。
- ボタンの設定画面を上に固定し、クリックで画面が下にずれる問題を修正。作り直してもスクロール位置が変わらないようにしました。
- オン/オフのあるボタン（ミュート系・サウンド）で、アイコンに画像・絵文字を使っているとき、オフのときに少し暗く表示します（PC・スマホ）。
- サウンドの設定画面の説明文を削除しました（「対応する形式」の1行は残しています）。
- スマホへ渡す画像アイコンの、オン/オフの状態が渡っていなかった不具合を修正。

## 電源
- **「スリープ」ボタンが、休止状態になることがあった不具合を修正**しました。休止状態が有効なPCでは、これまで休止状態になっていました。今は、設定に関係なく、必ずスリープになります。

## 安全性
- 壊れたバックアップなどで、アイコンの値が文字列でないとき、画面全体の描画が止まる不具合を修正。
- アプリ内から外部のリンクを開くとき、http(s) のリンクだけを開くようにしました。

## 診断（開発用）
- `node tools/mic-selftest.js --props` を追加しました。各マイクの設定情報（内蔵・USB・Bluetoothを見分ける手がかり）を、すべて表示して保存します（読むだけで、何も変更しません）。手順は `docs/マイク診断の手順.md` にあります。
